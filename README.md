# I_See_Your_Next_Song

2022 D&A Conference "이 노래는 어떻조"의 **[너의 다음 곡이 보여]** 프로젝트입니다.

[참고 영상 바로가기](https://www.youtube.com/watch?v=_BMc7duJJCg)

---

## 소개

**I_See_Your_Next_Song**은 사용자의 음악 취향을 분석하여 다음에 들으면 좋을 곡을 추천해주는 프로젝트입니다.  
2022 D&A Conference에서 발표된 "이 노래는 어떻조" 팀의 작품으로, 음악 추천 시스템의 새로운 가능성을 제시합니다.

## 주요 기능

- 사용자의 현재/최근 감상곡 기반 추천
- 음악 취향 분석 및 시각화
- 직관적인 UI/UX (웹 기반)
- 다양한 장르와 아티스트 지원

## 설치 및 실행 방법

1. **레포지토리 클론**
    ```
    git clone https://github.com/shjang2020/I_See_Your_Next_Song.git
    cd I_See_Your_Next_Song
    ```

2. **필요한 라이브러리 설치**
    ```
    pip install -r requirements.txt
    ```

3. **프로젝트 실행**
    ```
    python main.py
    ```

> 상세한 사용법은 각 폴더/파일 내의 설명을 참고해주세요.

## 사용 기술

- Python
- Flask (또는 Streamlit 등 웹 프레임워크)
- Pandas, Numpy 등 데이터 분석 라이브러리
- 기타 (추가 기술 스택 명시)
